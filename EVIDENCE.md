# Release evidence — 0.2.1-preview

**Executable experimental SDK chain implemented. Real CST execution, native
acceptance and real process observation: not_run. Numerical qualification and
physical certification: false.** Tests use injected interfaces and synthetic
fixtures; no research model or material spectrum was used.

## Verification

The final integrated command `python -B -m unittest discover -s tests -v`
passed **295 tests**. Python compilation, Draft 2020-12 schema and
both example validations passed. The skill frontmatter validator and independent
single-case application trial were checked separately. The suite count includes
all focused regressions; overlapping independent review scenarios are not added.

Test-first regressions cover native admission, fresh ownership, file replacement
and alias rejection, startup/cancellation/closure races, bounded SDK calls,
actual model/mode/mesh parsing, typed run/parameter/unit identity, raw 0D/complex
and reference data, fitted-response comparisons and independent material-loss
mapping. Worker integration checks failure result retention and immutable CPU
limits. Runtime tests cover explicit retry policy and content-bound integrity.

Independent transport, raw-result and whole-chain reviews used fake interfaces.
The whole-chain review invokes the real transport/model/result/facade/controller
implementations together with an injected SDK; it covers acceptance pending,
failed/unknown solver info, mesh/CPU mismatch, closure uncertainty and CLI routing.
These checks establish software behavior, not native compatibility or accuracy.
Patch regressions additionally cover actual pause/resume with cache and ownership
checks, completed-case preservation, new concurrent pause requests, and genuine
failure/cancellation distinction. Native readback comparisons use the expected
physical scale rather than a fixed volume floor. Contradictory raw curve readings
are preserved as invalid evidence. Explicit incident S-column and power-branch
identity must match the requested TE/TM mode before canonical analysis is emitted.
An additional independent joint-chain probe paused an injected running solver,
confirmed its owned closure, resumed through a second fresh session/attempt and
retained the native-validation-pending failure. Another resume created no third
session. The first receipt remained unchanged; this probe is not added to the
suite's test count and used no real SDK or process operation.
The `analyze-native` CLI tests use the actual converter with synthetic raw trees
and profiles, keep one explicit case, preserve mapping errors and prove that no
backend/runtime/vendor import occurs. The same saved export is analyzed without
another simulation; PEC-derived zero transmission is labeled as an assumption.

Verified environment: Python 3.12.7, NumPy 2.3.5, Trimesh 4.11.5,
Matplotlib 3.10.8 and JSON Schema 4.26.0. Other allowed dependency versions have
not been exhaustively tested. No installation or native execution was performed.

## Independent skill-use trial

A fresh agent completed the single-case request before SKILL.md existed; another
fresh agent read the finished skill and repeated the task. Both preserved one
design, with no parameter scan or solver call. These application trials establish
usability; the baseline already followed the scope, so they do not establish a
measured improvement in rule compliance.

The final trial ran help/validate/plan/analyze/plot once each, then the exported
standalone plotting script once. All returned zero. The actual PNG was visually
checked: material domains sit outside the data axes, points are visible and zero
markers have a stated display policy. PNG content matched after rerunning the
standalone script in the same environment. SVG is editable, but generation dates
and generated element IDs prevent a byte-for-byte SVG reproducibility claim.

[examples/preview](examples/preview) contains the final synthetic demonstration:
metrics JSON, actual-point CSV, PNG, SVG, plot style/versions and a standalone
Python script. Its source fixtures are `examples/single.json`,
`synthetic_spectra.csv` and `synthetic_power.csv`.

## Release boundary

`MANIFEST.json` records every released file's SHA-256 and byte size. The archive
contains original generic code, documentation, synthetic examples and tests,
including `.gitignore` for private inputs, native assets and output directories.
The release builder includes only tracked files in the explicit distribution
categories. Git history, private work/review logs, user paths/accounts, vendor
SDK/help content, research materials, native models and solver results are excluded.
Ignore rules do not remove data already tracked; inspect each release manifest.
No license is selected and extraction does not install or alter an environment.

Remaining physical/build-specific gates are listed in
[cst-validation.md](references/cst-validation.md). SDK caller timeouts may leave a
request pending; uncertain closure retains the controller lock. Pathname-based
SDK saving has an unavoidable check/use window despite identity/alias guards.
An offline test or completed solver call does not establish convergence,
fitting accuracy, phase reference or numerical certification.
